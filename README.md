# 🏃 Fit Poradce - Aplikace pro odhad kalorií

Fit Poradce je jednoduchá aplikace, která vám pomůže odhadnout kalorie z popisu jídla a doporučí jídelníček na zbytek dne.

## 📁 Struktura projektu

```
fit-poradce/
├── index.html                 # Vstupní stránka s ceníkem
├── CLAUDE.md                  # Dokumentace + skills pro aplikaci
├── .claude/
│   └── settings.local.json   # Nastavení Claude Code
└── README.md                  # Tento soubor
```

## 🚀 Jak to funguje

### 1. Vstupní stránka
- **URL**: https://jasminova663-create.github.io/fit-poradce/
- **Obsah**: Moderní landing page s cenovými plány
- **Designs**: Responsive design pro mobile i desktop

### 2. Aplikace Fit Poradce
- Běží přes **Claude Code** (bez serveru)
- Používá **skills** pro:
  - Odhad kalorií z popisu jídla
  - Doporučení jídelníčku na zbytek dne

### 3. Dokumentace
- **CLAUDE.md**: Kompletní průvodce se skills a instrukcemi

## 💡 Modelový uživatel

- **Pohlaví**: Muž
- **Věk**: 50 let
- **Výška**: 190 cm
- **Hmotnost**: 105 kg
- **Zaměstnání**: Sedavé
